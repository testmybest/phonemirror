# PhoneMirror - 手机投屏到笔记本

一个高性能、低延迟的手机投屏软件，支持 Android 和 iOS 设备无线投屏到 Windows/macOS/Linux 笔记本电脑。

## 核心特性

- **超低延迟**: 端到端延迟 < 100ms
- **高流畅度**: 支持 30-60fps，自适应码率
- **跨平台**: 支持 Android/iOS 投屏到 Windows/macOS/Linux
- **无线连接**: 基于 WebRTC，无需数据线
- **双向控制**: 支持鼠标键盘控制手机
- **高清画质**: 支持 1080p/2K 分辨率

## 技术架构

### 传输协议
- **WebRTC**: P2P 直连，NAT 穿透
- **视频编码**: H.264 硬件加速
- **音频**: AAC 编码
- **信令**: WebSocket

### 系统架构
```
手机端 (Sender)                    电脑端 (Receiver)
┌─────────────────┐              ┌─────────────────┐
│ 屏幕捕获         │              │   WebRTC 接收    │
│ (MediaProjection)│  ────────>   │   视频解码       │
├─────────────────┤   WebRTC     ├─────────────────┤
│ H.264 硬件编码   │   DataChannel │   渲染显示       │
├─────────────────┤              ├─────────────────┤
│ 输入事件注入     │  <────────   │   输入捕获       │
│ (Accessibility) │              │   (鼠标/键盘)    │
└─────────────────┘              └─────────────────┘
```

## 安装使用

### 手机端 (Android)
1. 安装 PhoneMirror APK
2. 开启"USB调试"和"无线调试"
3. 授予屏幕录制权限

### 电脑端
1. 下载对应系统的安装包
2. 运行 PhoneMirror 应用
3. 扫描二维码或输入配对码连接
